# Simulasi Kehidupan & Strategi Finansial (Game Master Simulator)

Game simulasi kehidupan, karier, bisnis, dan pengelolaan kekayaan yang realistis berbasis probabilitas, dinamika ekonomi makro, dan efek putaran kedua (*second-order effects*).

## Fitur Utama
- **Dashboard Finansial Real-time**: Memantau Net Worth, Free Cash Flow bulanan, rasio cadangan kas (likuiditas), utang, stamina fisik, dan beban stres.
- **Engine Ekonomi & Keputusan Strategis**: Setiap pilihan dianalisis berdasarkan modal, ROI, risiko, opportunity cost, beban waktu, dan reversibilitas.
- **Second-Order Effects**: Keputusan di ronde awal langsung memengaruhi daya tawar karier, ketahanan krisis, dan opsi bisnis di ronde berikutnya.
- **Audit Kinerja Berkala**: Evaluasi objektif setiap 5 ronde dan laporan akhir 20 ronde dilengkapi visualisasi grafik Net Worth via Chart.js.

## Cara Menjalankan
Buka file `index.html` langsung di browser, atau jalankan server lokal:
```bash
python -m http.server 3000
```
Buka di browser: `http://localhost:3000`
